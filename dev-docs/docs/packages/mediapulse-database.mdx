## Purpose

`@workspace/mediapulse-database` is the Prisma package for Mediapulse-specific data such as tickers, newsletters, search queries, and knowledge graph entities.

## Exports

- **Default:** Prisma client instance (`prisma`) and `Prisma` namespace.
- **`@workspace/mediapulse-database/client`** — Alternative client entry for custom instantiation and tests.

## Environment variables

| Variable                  | Description                                              |
| ------------------------- | -------------------------------------------------------- |
| `MEDIAPULSE_DATABASE_URL` | Primary connection string for Mediapulse schema/tables.  |
| `DATABASE_URL`            | Fallback connection string when Mediapulse URL is unset. |
| `DATABASE_CERT_BASE64`    | Optional base64 CA certificate for SSL connections.      |

## Key models

- `Ticker`, `UserTicker`, `SearchQuery`
- `Newsletter`
- `DataSource`, `DataSourceExpansion`
- `EntityType`, `RelationType`, `Entity`, `EntityAlias`, `TickerEntity`, `EntityRelation`
- `ArticleEntity`, `ArticleRelevance`
