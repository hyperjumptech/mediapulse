## Purpose

Database access is split into two Prisma packages:

- **[orchestration-database](/packages/orchestration-database)** — `@hermes/orchestration-database` (users, API keys, pipelines, schedules, executions, variables, registry).
- **[mediapulse-database](/packages/mediapulse-database)** — `@mediapulse/database` (tickers, newsletters, knowledge graph, Mediapulse-only tables).

Use the package that owns the models you query; see each page for env vars, exports, and migrations.
