## Purpose

`@workspace/database` is a wrapper around the Prisma v7 client. It supports the shared schema and **SSL connections** (via `DATABASE_CERT_BASE64`). All apps that need persistence use this package.

## Exports

- **Default:** Prisma client instance (`prisma`) and `Prisma` namespace.
- **`@workspace/database/client`** — Alternative client entry (e.g. for custom instantiation or tests).

## Features

- **Schema:** Single Prisma schema; migrations in the package.
- **SSL:** Set `DATABASE_CERT_BASE64` with the base64-encoded certificate and use `sslmode=require` in the connection URL.
- **Scripts:** `db:migrate:dev`, `db:migrate:deploy`, `db:generate`, `db:push`, `studio`.

## Environment variables

| Variable               | Description                                   |
| ---------------------- | --------------------------------------------- |
| `DATABASE_URL`         | PostgreSQL connection string.                 |
| `DATABASE_CERT_BASE64` | Optional; base64-encoded certificate for SSL. |

## Consumers

Hermes, Dashboard, agent-auth-api, agent-data-api, agent-registry-api, idx-tickers-importer (via DI).
