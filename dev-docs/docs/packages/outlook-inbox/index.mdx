## Purpose

`@mediapulse/outlook-inbox` connects to a Microsoft Outlook inbox using the Microsoft Graph API. Consumers can list messages with filters (subject equals/contains, received date, unread) and process them by archiving (default) or moving to Deleted Items.

## Main exports

- **`createOutlookInboxClient(config, options?)`** — Creates the inbox client. Config: either `getAccessToken` (custom token) or `clientId`, `clientSecret`, `tenantId` (client credentials). Optional `userId` (default `"me"`).
- **`client.listMessages(filter, options?)`** — Lists messages matching the filter; optional `top` for page size.
- **`client.processMessages(filter, options?)`** — Lists matching messages and moves them to archive or deleted items. Options: `action` (`'archive'` \| `'delete'`, default `'archive'`), `maxMessages`.
- **`client.archiveMessage(messageIdOrIds)`** / **`client.deleteMessage(messageIdOrIds)`** — Archive or delete one or more messages. Accept `string` or `string[]`; return `Promise<GraphMessage[]>`.
- **Types:** `OutlookInboxConfig`, `MessageFilter`, `ProcessMessagesOptions`, `GraphMessage`.

## Config and filters

- **Auth:** Pass `getAccessToken()` for full control, or `clientId`, `clientSecret`, `tenantId` for app-only client credentials. Use `userId` for the mailbox (e.g. app-only); omit for `"me"`.
- **Filter:** `subjectEquals`, `subjectContains`, `receivedAfter`, `receivedBefore`, `isUnread`. All optional; combined with AND.

## Archive vs delete

- **Archive** (default): moves to the Outlook Archive folder (One-Click Archive).
- **Delete**: moves to Deleted Items (recoverable). No permanent delete in the public API.
