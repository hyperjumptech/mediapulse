## Purpose

`@workspace/env` provides **type-safe environment variables** generated from `env.example` (and per-agent example files) using env-to-t3. Never use `process.env` directly; import from `@workspace/env` or a subpath.

## Exports

- **`.`** — Main app env (from `env.example`).
- **`./agents-content-generation`** — Env for content-generation agent.
- **`./agents-data-collection`** — Env for data-collection agent.
- **`./agents-delivery`** — Env for delivery agent.

## Usage

```ts
import { env } from "@workspace/env";
const dbUrl = env.DATABASE_URL;
```

```ts
import { env } from "@workspace/env/agents-data-collection";
const apiKey = env.SERPER_API_KEY;
```

## Build

After changing any `env*.example` file, run `pnpm build` in `packages/env` to regenerate the TypeScript output. Sensitive values must **not** use the `NEXT_PUBLIC_` prefix (server-only).

## Consumers

All apps and agents; each uses the main export or the appropriate agent subpath.
