## Purpose

Environment variables are split by domain:

- **`@hermes/env`** — Hermes apps (dashboard, worker, agent-auth-api, agent-registry-api) and orchestration DB. Generated from `packages/hermes/env/env.example` and `env.hermes-worker.example`.
- **`@mediapulse/env`** — Mediapulse apps (agent-data-api, user-registration, domain-api) and agents. Generated from `packages/mediapulse/env/env.example` and `env.agents.*.example` files.

Never use `process.env` directly; import from `@hermes/env`, `@mediapulse/env`, or the documented subpath (for example `@mediapulse/env/agents-data-collection`).

## Exports (Mediapulse)

- **`.`** — Main Mediapulse app env.
- **`./agents-content-generation`** — Env for content-generation agent.
- **`./agents-data-collection`** — Env for data-collection agent.
- **`./agents-delivery`** — Env for delivery agent.
- **`./agents-ticker-echo`** — Env for ticker-echo agent.

## Usage

```ts
import { env } from "@hermes/env";
const dbUrl = env.DATABASE_URL;
```

```ts
import { env } from "@mediapulse/env/agents-data-collection";
const apiKey = env.SERPER_API_KEY;
```

## Build

After changing any `env*.example` file, run `pnpm build` in `packages/hermes/env` and/or `packages/mediapulse/env` to regenerate the TypeScript output. Sensitive values must **not** use the `NEXT_PUBLIC_` prefix (server-only).

## Consumers

Hermes apps use `@hermes/env` (and `@hermes/env/hermes-worker` for the worker). Mediapulse apps and agents use `@mediapulse/env` and agent subpaths. **hermes-worker** requires `PG_DATAQUEUE_DATABASE` for the scheduler; DataQueue migrations are run from that app (`pnpm --filter @hermes/worker run migrate-dataqueue`).

## Agent-specific overrides (development)

Agents can override **per-agent** values via **`.env.local`** in each agent app:

- **`PORT`** — e.g. 4001 (data-collection), 4002 (content-generation), 4003 (delivery).
- **`AGENT_PUBLIC_URL`** — URL where that agent is reachable (e.g. `http://localhost:4003`).
- **`AGENT_REGISTRY_API_KEY`** — optional; can differ per agent when auto-registering with the registry.
