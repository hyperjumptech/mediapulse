## Purpose

`@workspace/mediapulse-hermes-integration` contains Mediapulse-specific expansion helpers that can be used by a Mediapulse-owned runtime (for example, `apps/mediapulse-domain-api`).

The package bridges:

- generic `db:` syntax parsing (`@workspace/hermes-step-input-syntax`), and
- **Mediapulse** Prisma expansion (`expandDataSources` / `findMany`).

## Main exports

- `createMediapulseExpandStepInputs` — Factory helper for in-process expansion wiring.
- `expandSingleDataSource` / `expandDataSources` — Runtime expansion against a Mediapulse `PrismaClient`.

## Notes

- Hermes no longer queries Mediapulse DB directly.
- Preferred production path is HTTP: Hermes calls a domain integration API, and that service uses this package internally.
