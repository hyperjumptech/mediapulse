## Purpose

Dashboard is a Next.js app that provides a separate interface for users to manage their account. It shares the same stack as Hermes (Next.js, route-action-gen, `@workspace/database`, `@workspace/ui`) but is a distinct deployable app.

## Features

- **Login** — Session-based authentication (e.g. email/password with bcrypt).
- **Dummy dashboard** — Currently a dummy dashboard that shows nothing.

## Key routes / entrypoints

- Login: `/auth/login` (or `/login`) with POST action for credentials.
- Post-login dashboard or home (app-specific routes).

## Port

- Default Next.js dev port (typically **3000**; ensure it does not clash with Hermes on 3001 when running both).

## Workspace dependencies

- `@workspace/database` — Prisma client for users/sessions.
- `@workspace/env` — Environment variables.
- `@workspace/logger` — Logging.
- `@workspace/ui` — Shared UI components.
