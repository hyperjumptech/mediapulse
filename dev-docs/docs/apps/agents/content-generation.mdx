## Purpose

The content-generation agent takes **data sources** (from the data-collection agent, stored via agent-data-api) and produces a **newsletter** (subject, content, optional description) using OpenAI. It then stores the result via agent-data-api for the delivery agent to consume.

## Features

- **Input:** `tickerId` (and optional fields). Receives bearer token from Hermes.
- **Fetches** existing data-collection output for the ticker from agent-data-api (`/api/data-collection` or content-generation endpoint as defined).
- **Calls OpenAI** to generate structured newsletter content (subject, executive summary, top news items).
- **Stores** generated content via agent-data-api for the delivery agent.
- **Skips** with a clear message if no data sources are found.

## Entrypoint

- **Main:** `src/index.ts` — Exports a Bun/Hono-compatible `fetch` and `port` (default **4002**).

## Port

- **4002** (default from `env.PORT`).
