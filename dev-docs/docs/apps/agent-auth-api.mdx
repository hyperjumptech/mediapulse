## Purpose

agent-auth-api is a Hono server that manages **API keys** (create, list, get, update, delete, deactivate, reactivate), issues **short-lived JWT tokens** for agent invocation, and exposes **token verification** for other services (e.g. agents and agent-data-api). Agents and the data API use it to validate `Authorization: Bearer <token>`.

## Features

- **POST /api/verify** — Verify a bearer token (no basic auth). Accepts **raw API keys** (lookup by hash) or **short-lived JWTs** (signature and expiry check). Used by agents and agent-data-api.
- **POST /api/token** — Issue a short-lived JWT (e.g. 15 min) for agent invocation. Caller sends `Authorization: Bearer <api_key>`. The API key must be active and have **purpose `scheduler`**. Requires `AGENT_AUTH_JWT_SECRET` to be set. Used by hermes-worker (and optionally Hermes) so they send JWTs to agents instead of the raw key.
- **API key CRUD** — Create, retrieve (list + by id), update, delete API keys. Create accepts optional **purpose** (`general`, `scheduler`, `run_pipeline`). Use `scheduler` for keys that hermes-worker uses to obtain tokens.
- **Deactivate / reactivate** — Soft-disable keys without deleting. Revoking a scheduler key stops hermes-worker from obtaining new tokens after the next refresh.
- **Temporary admin auth** — API key management is protected by HTTP Basic Auth (`TEMP_ADMIN_USERNAME` / `TEMP_ADMIN_PASSWORD`) until a proper admin flow exists.

## Key routes

| Method | Path                           | Description             |
| ------ | ------------------------------ | ----------------------- |
| POST   | `/api/verify`                  | Verify bearer token/JWT |
| POST   | `/api/token`                   | Issue short-lived JWT   |
| POST   | `/api/api-keys`                | Create API key          |
| GET    | `/api/api-keys`                | List API keys           |
| GET    | `/api/api-keys/:id`            | Get one API key         |
| PATCH  | `/api/api-keys/:id`            | Update API key          |
| DELETE | `/api/api-keys/:id`            | Delete API key          |
| POST   | `/api/api-keys/:id/deactivate` | Deactivate              |
| POST   | `/api/api-keys/:id/reactivate` | Reactivate              |

## Environment

- **AGENT_AUTH_JWT_SECRET** (optional) — Secret for signing short-lived JWTs. Required for POST /api/token. Use a long random value (e.g. 32+ chars) in production.

## Port

- **8080** (default from `env.PORT`).

## Workspace dependencies

- `@workspace/api-utils` — Error helpers (e.g. `internalError`, `notFound`).
