## Purpose

agent-data-api is a Hono server that exposes **data endpoints** used by the agents (currently content-generation, data-collection, delivery). All routes are protected by **bearer auth**; the token is verified via `@workspace/agent-auth-client` against agent-auth-api.

## Features

- **Bearer auth** — Every request must include `Authorization: Bearer <api_key>`. API keys are verified via agent-auth-api `POST /api/verify-api-key` (agents use admin-issued API keys to call this service).
- **Content-generation** — GET/POST for content-generation data (e.g. store/retrieve generated newsletter content).
- **Data-collection** — GET/POST for data-collection data (e.g. store/retrieve collected pages/sources).
- **Delivery** — GET/POST for delivery data (e.g. newsletter content + subscribers for sending).

Agents use `dataApiGet` / `dataApiPost` from `@workspace/agent-runtime` to call these endpoints with their **admin-issued API key** (not the invocation JWT).

## Key routes

| Method | Path                      | Description                                    |
| ------ | ------------------------- | ---------------------------------------------- |
| GET    | `/api/content-generation` | Get content-generation data (e.g. by tickerId) |
| POST   | `/api/content-generation` | Store content-generation payload               |
| GET    | `/api/data-collection`    | Get data-collection data                       |
| POST   | `/api/data-collection`    | Store data-collection payload                  |
| GET    | `/api/delivery`           | Get delivery data (newsletter + subscribers)   |
| POST   | `/api/delivery`           | Store delivery payload                         |

## Port

- **8081** (default from `env.PORT`).

## Workspace dependencies

- `@workspace/agent-auth-client` — `verifyApiKeyViaAuthApi` for bearer (API key) auth.
- `@workspace/agent-types` — Shared types for request/response shapes.
- `@workspace/api-utils` — Error helpers.
- `@workspace/env` — Environment (including `AGENT_AUTH_API_URL`).
- `@workspace/database` — Prisma for reading/writing agent data.
- `@workspace/logger` — Pino logger.
