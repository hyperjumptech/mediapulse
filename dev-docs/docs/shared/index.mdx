Code under **`packages/shared/`** is published as **`@workspace/*`** and imported via `workspace:*` in `package.json`.

This section holds documentation that is **clearly monorepo-wide** (starting with the UI kit). Deeper package pages for the agent stack, logger, and similar often live under **[Hermes → Packages](/hermes/packages)** because the orchestration and agent story is maintained there; Mediapulse-owned packages are under **[Mediapulse → Packages](/mediapulse/packages)**. Prefer **one** canonical page per package and link to it from here when needed.
