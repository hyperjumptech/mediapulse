Follow the steps in this page to start developing MediaPulse.

## Prerequisites

- Node.js 22+
- pnpm 10.4.1
- Docker
- PostgreSQL

## Installation

```bash
git clone <repository-url>
cd mediapulse
pnpm install
```

Remember that this project uses PNPM as the package manager. Don't use `npm`, `yarn`, or `bun` to install dependencies.

### Setup Environment Variables

Run one of the following commands to setup the environment variables:

```bash
./dev-bootstrap.sh
./dev-bootstrap.sh -f # to remove existing .env and .env.local files first
```

The script merges all `env.*.example` files into `packages/env/.env`, then creates symlinks so apps and packages use that shared file. **Agent apps** (e.g. `apps/agents/delivery`) also get a **per-agent `.env.local`** (created from `env.agents.<name>.example`) so you can set `PORT`, `AGENT_PUBLIC_URL`, and `AGENT_REGISTRY_API_KEY` per agent without affecting others. Edit `apps/agents/<name>/.env.local` for agent-specific overrides.

The example files already contain the correct values for some environment variables for development purposes. But you still need to add the correct values for the following environment variables in the generated `.env` file (and in each agent’s `.env.local` if you use registry/URL overrides):

| Environment Variable | Description                                                                                   |
| -------------------- | --------------------------------------------------------------------------------------------- |
| JINA_API_KEY         | The API key for the Jina AI API. Get it from the landing page of [Jina.ai](https://jina.ai)   |
| SERPER_API_KEY       | The API key for the Serper API. Create a new free account in [Serper.dev](https://serper.dev) |
| OPENAI_API_KEY       | The API key for the OpenAI API. Create a new free account in [OpenAI](https://openai.com)     |

<Callout type="info">
  Remember that the `packages/env/.env` file is the source of truth for the
  environment variables during development.
</Callout>

### Development database

To run the development database, run the following command:

```bash
docker-compose up
```

This will start the PostgreSQL database.

### Setup database (Prisma)

```bash
cd packages/database
pnpm db:migrate:dev && pnpm db:generate
cd ../..
```

### Create an admin user

Run the following command to create an admin user:

```bash
cd apps/hermes && pnpm create:admin <email> <password>
```

### Generate an API key for the agents

Run the following command to generate an API key for the agents:

```bash
cd apps/hermes && pnpm generate-api-key
```

The script will print the API key. Set this value in the `AGENT_REGISTRY_API_KEY` environment variable in the agent's `.env.local` files (`apps/agents/<name>/.env.local`).

### Running all apps (`pnpm dev`)

When you run `pnpm dev`, Turbo starts every app’s dev server. Each app is bound to a different port so they can run together:

| App                      | Port |
| ------------------------ | ---- |
| dashboard                | 3000 |
| hermes                   | 3001 |
| agent-auth-api           | 8080 |
| agent-data-api           | 8081 |
| agent-registry-api       | 8082 |
| data-collection agent    | 4001 |
| content-generation agent | 4002 |
| delivery agent           | 4003 |
