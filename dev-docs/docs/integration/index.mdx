This section is the **bridge** between **[Hermes](/hermes)** (agent orchestration, dashboard, worker, orchestration database) and **[Mediapulse](/mediapulse)** (product data, agents, Mediapulse database). Use it when you need the full picture of how the two systems talk to each other.

Hermes and Mediapulse docs are written to stand alone: Hermes describes orchestration and **generic** external-domain integration; Mediapulse describes the product and its agents. **Here** we document **this monorepo’s** wiring—env vars, registration, and concrete HTTP flows.
