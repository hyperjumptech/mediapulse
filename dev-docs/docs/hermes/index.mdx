**Hermes** is the orchestration domain: pipelines, schedules, the dashboard, **agent-auth-api**, **agent-registry-api**, **hermes-worker**, and the orchestration database.

Use the sidebar **Apps** and **Packages** groups to browse:

- **Apps** — [Dashboard](/hermes/apps/dashboard), [Data source expansion](/hermes/apps/data-source-expansion), [Worker](/hermes/apps/hermes-worker), [agent-auth-api](/hermes/apps/agent-auth-api), [agent-registry-api](/hermes/apps/agent-registry-api).
- **Packages** — [Overview](/hermes/packages), [orchestration-database](/hermes/packages/orchestration-database), [env](/hermes/packages/env), [scheduler](/hermes/packages/hermes-scheduler), and shared `@workspace/*` libraries.

For how Hermes relates to Mediapulse, see [Hermes and Mediapulse domains](/architecture/domains).
