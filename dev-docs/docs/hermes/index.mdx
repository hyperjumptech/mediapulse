**Hermes** is an advanced and efficient agent orchestration system. It is responsible for scheduling and executing agent pipelines. It also provides a dashboard for managing the orchestration of agents.

**Hermes doesn't perform any business logic.** It is only responsible for orchestrating the execution of agents. The external system that owns agents are integrated with Hermes via HTTP (`@hermes/domain-contract`). This integration is called [Domain integration](#domain-integration).
