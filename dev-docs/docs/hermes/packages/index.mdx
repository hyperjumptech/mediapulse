Hermes uses **`packages/hermes/*`** and **`packages/shared/*`** (published as **`@workspace/*`**). Mediapulse-owned Prisma and integrations are documented under **[Mediapulse → Packages](/mediapulse/packages)**. The **shared UI kit** (`@workspace/ui`) is under **[Shared](/shared)**.

Apps reference workspace packages with `workspace:*` in `package.json`.

## Hermes domain packages

| Package                                                               | npm name                           | Role                                                                |
| --------------------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------- |
| [orchestration-database](/hermes/packages/orchestration-database)     | `@hermes/orchestration-database`   | Prisma: users, API keys, pipelines, schedules, executions, registry |
| [env](/hermes/packages/env)                                           | `@hermes/env` (and worker subpath) | Type-safe env for Hermes apps and orchestration DB                  |
| [hermes-scheduler](/hermes/packages/hermes-scheduler)                 | `@hermes/scheduler`                | Schedule execution, step expansion hooks                            |
| [hermes-step-input-syntax](/hermes/packages/hermes-step-input-syntax) | `@hermes/step-input-syntax`        | Generic `db:table:field?…` parsing (not Mediapulse-specific)        |
| [hermes-domain-contract](/hermes/packages/hermes-domain-contract)     | `@hermes/domain-contract`          | HTTP contract and client for Hermes ↔ domain API                    |

## Database entrypoint

- **[database](/hermes/packages/database)** — Short overview; use **[orchestration-database](/hermes/packages/orchestration-database)** for Hermes migrations and **[mediapulse-database](/mediapulse/packages/mediapulse-database)** for Mediapulse migrations.

## Consumers (summary)

| Package                            | Typical consumers                                            |
| ---------------------------------- | ------------------------------------------------------------ |
| `@hermes/orchestration-database`   | Hermes dashboard, worker, agent-auth-api, agent-registry-api |
| `@hermes/env`                      | Hermes apps, orchestration consumers                         |
| `@workspace/agent-runtime`         | Mediapulse agents                                            |
| `@workspace/agent-data-api-client` | Agents that call agent-data-api                              |
