## Purpose

`@hermes/orchestration-database` is the Prisma package for the orchestration domain: users, pipelines, pipeline steps, schedules, executions, variables, domain integration registry data, and encrypted payloads (including domain integration credentials).

## Exports

- **Default:** Prisma client instance (`prisma`) and `Prisma` namespace.
- **`@hermes/orchestration-database/client`** — Alternative client entry for custom instantiation and tests.

## Environment variables

| Variable                     | Description                                                 |
| ---------------------------- | ----------------------------------------------------------- |
| `ORCHESTRATION_DATABASE_URL` | Primary connection string for orchestration schema/tables.  |
| `DATABASE_URL`               | Fallback connection string when orchestration URL is unset. |
| `DATABASE_CERT_BASE64`       | Optional base64 CA certificate for SSL connections.         |

## Key models

- `User`, `EncryptedPayload`, `AgentRegistry`, `AgentConfig`
- `DomainIntegration` (base URL + metadata for self-registered domain services)
- `DataSourceExpansionTemplate` — saved `db:…` expansion strings for the Hermes dashboard (FK to `DomainIntegration`; preview still uses the domain API)
- `Pipeline`, `PipelineStep`, `Schedule`, `ScheduleExecution`, `AgentJobExecution`
- `Variable`
