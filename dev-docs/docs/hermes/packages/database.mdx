## Purpose

Hermes data lives in **`@hermes/orchestration-database`** — Prisma models for **admin** users (dashboard accounts), API keys, pipelines, schedules, executions, variables, agent registry metadata, and domain integration registration.

Use **[orchestration-database](/hermes/packages/orchestration-database)** for env vars, exports, and migrations.

## Other databases in the monorepo

Product (non-orchestration) Prisma packages are documented under **Mediapulse** — for example **[mediapulse-database](/mediapulse/packages/mediapulse-database)**. Hermes does not query those databases for domain integration features; it calls the registered domain HTTP API instead. See [Hermes–Mediapulse integration](/integration/domains).
