Article knowledge is moving out of Mediapulse's own `knowledge_*` tables into the MediaPulse knowledge graph in Organon. This page tracks that work. When a step is done, move it to [Done](#done) with its date and pull request.

## Where it stands

Last updated 2026-11-18.

| Part               | State                                                                                                                                                                                                                                                                                   |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sending            | [knowledge-ingestion](/mediapulse/apps/agents/knowledge-ingestion) 2.0.0 runs nightly at 03:00 WIB. It sends up to 20 articles a night that article analysis placed for tickers with active subscribers, and checks the evidence of the night before.                                  |
| Reading            | Organon reads each article with Haiku 5.5, an output limit of 32,000 tokens and reasoning set to Low. A read costs about $0.005.                                                                                                                                                        |
| Concepts           | Production is on version 8. Every fact is tied to its sentence by one article point (`mp:ArticlePoint`), which holds the quote, the article, the item it supports and the tickers.                                                                                                     |
| Checking           | A report-only routine writes `reports/knowledge-graph/<date>.md` every morning at 08:00. The `knowledge-graph-maintenance` skill turns the report into fixes, and the `knowledge-graph-duplicates` skill audits the whole graph with `pnpm knowledge-graph:duplicates`.               |
| Old knowledge base | Still in the code and the database. It goes once the new path has run cleanly for a week.                                                                                                                                                                                              |

## Watch list

- **Articles placed for the wrong ticker.** Codes that are also acronyms or foreign company names, like ADES and DOOH, let in articles about something else. Ambiguous names stop them at the keyword gate.
- **General news on narrow tickers.** On 2026-11-18, 9 of 17 articles were ministry or industrial-estate news placed for AMAN. They cost a read each and add mostly officials' quotes.
- **Duplicates.** Organon matches a new item by exact label within one class family, so the same body or deal keeps coming back under another name. Run the duplicate audit about once a week.
- **Read again on old jobs.** A job from before Concepts 8 still lists the old classes, so Read again in the dashboard adds no points. Send a fresh ingestion instead.
