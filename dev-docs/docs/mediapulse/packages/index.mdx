Mediapulse product code lives under **`packages/mediapulse/`** and **`apps/mediapulse/`**.

Shared **`@workspace/*`** libraries used by agents and APIs are mostly documented under **[Hermes → Packages](/hermes/packages)** (agent stack, logger, and similar). The **UI kit** (`@workspace/ui`) is under **[Shared](/shared)**.

## Mediapulse domain packages

| Package                                                                             | npm name                           | Role                                                     |
| ----------------------------------------------------------------------------------- | ---------------------------------- | -------------------------------------------------------- |
| [mediapulse-database](/mediapulse/packages/mediapulse-database)                     | `@mediapulse/database`             | Prisma: tickers, newsletters, KG, Mediapulse-only tables |
| [mediapulse-hermes-integration](/mediapulse/packages/mediapulse-hermes-integration) | `@mediapulse/hermes-integration`   | Mediapulse Prisma expansion for domain-api               |
| [knowledge-graph](/mediapulse/packages/knowledge-graph)                             | `@mediapulse/knowledge-graph`      | Knowledge graph SPARQL client and ticker sync            |
| [outlook-inbox](/mediapulse/packages/outlook-inbox)                                 | `@mediapulse/outlook-inbox`        | Outlook / Microsoft Graph helpers                        |

Environment variables for Mediapulse apps and agents are built from **`packages/mediapulse/env`** (T3 Env / env-to-t3); run `pnpm build` there after changing `env*.example` files. Hermes apps use [@hermes/env](/hermes/packages/env) separately.

## Consumers (summary)

| Package                            | Typical consumers                                                |
| ---------------------------------- | ---------------------------------------------------------------- |
| `@mediapulse/database`             | agent-data-api, domain-api, Mediapulse tooling                   |
| `@mediapulse/env`                  | agent-data-api, domain-api, user-registration, Mediapulse agents |
| `@mediapulse/hermes-integration`   | domain-api                                                       |
| `@mediapulse/knowledge-graph`      | agent-data-api (ticker profiles), domain-api (ticker sync)       |
