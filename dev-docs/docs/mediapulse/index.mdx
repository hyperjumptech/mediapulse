**Mediapulse** is the system that contains busniss logic and the agents to create daily newsletters. It is the product data domain: **agent-data-api**, **domain-api**, **user-registration**, HTTP **agents**, and Mediapulse Prisma packages (tickers, newsletters, knowledge graph, subscribers, and related tables).

User chooses the tickers they want to keep track of and the system will create a daily newsletter for them using the agents.

## How this connects to Hermes

Orchestration, JWT minting, and the domain HTTP contract live in **[Hermes](/hermes)**. **How Mediapulse integrates with Hermes** (databases, env, `domain-api` registration) is documented in **[Hermes–Mediapulse integration](/integration)** — start with [Hermes and Mediapulse domains](/integration/domains).
