## Overview

In production, the content-generation agent receives its OpenAI credentials from the Hermes config payload on each invocation. The `@mediapulse/env/agents-content-generation` module does **not** expose an `OPENAI_API_KEY` — the API key comes exclusively from the agent config selected for the pipeline step in Hermes (Dashboard → Agent configs).

For local development only, the agent accepts an OpenAI API key via the legacy `openaiApiKey` top-level config field or the `openai.apiKey` field. You can inject these through `.env.local` for convenience.

<Callout type="warning">
**Production warning:** `OPENAI_API_KEY` in the environment is a **local-dev convenience only** and **must not** be used in production. In production, all credentials come from Hermes config (see [FR2](/mediapulse/apps/agents/content-generation-config-reference#openai)). Do not deploy an agent image with `OPENAI_API_KEY` set in the runtime environment.
</Callout>

## Local setup (step by step)

1. **Copy the env template:**
   ```bash
   cp packages/mediapulse/env/.env .env.local
   ```

2. **Set your OpenAI API key:**
   Open `.env.local` and add the key to the Hermes agent config you select for local runs (via the Hermes Dashboard Agent configs form) or inject it as the legacy `openaiApiKey` field in your local config payload. The `@mediapulse/env/agents-content-generation` typed env module does not include `OPENAI_API_KEY`, so do not add it there.

3. **Run the agent locally:**
   ```bash
   pnpm --filter @mediapulse/content-generation dev
   ```
   This starts the agent on port `4002` with hot reload.

4. **Verify the key is not committed:**
   `.env.local` is gitignored by default in this repository. Never commit any file containing real API keys.

## How the agent resolves credentials

1. The agent receives a config payload from Hermes (or test harness) on each `POST /` invocation.
2. The config is validated against `ContentGenerationConfigSchema`.
3. The agent reads `config.openai.apiKey` first, then falls back to the deprecated `config.openaiApiKey`.
4. If neither is provided, the config is rejected during schema validation with a clear error message.

## Typed env module

The agent uses `@mediapulse/env/agents-content-generation` for its runtime environment:

```ts
import { env } from "@mediapulse/env/agents-content-generation";
```

Available keys: `PORT`, `AGENT_DATA_API_URL`, `AGENT_AUTH_API_URL`, `AGENT_REGISTRY_URL`, `AGENT_PUBLIC_URL`, `DOMAIN_INTEGRATION_API_KEY`, `DOMAIN_INTEGRATION_ID`.

There is **no** `OPENAI_API_KEY` in this module.
