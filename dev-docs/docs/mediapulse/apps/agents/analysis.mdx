## Purpose

The analysis agent is the KG intelligence step. It converts collected articles into structured graph updates and relevance scores.

Core responsibilities:

1. Extract entities and relationships from articles.
2. Upsert KG records (`entity`, `entity_alias`, `ticker_entity`, `entity_relation`, `article_entity`).
3. Score article relevance and mark top-K rows as `selected` in `article_relevance`.

## Relevance scoring signals

| Signal          | Weight | Description                                      |
| --------------- | ------ | ------------------------------------------------ |
| `aliasMatch`    | `0.30` | Symbol/name/alias match against article text     |
| `entityOverlap` | `0.30` | Overlap between extracted entities and ticker KG |
| `freshness`     | `0.20` | Recency score                                    |
| `sourceQuality` | `0.10` | Source trust score                               |
| `novelty`       | `0.10` | Dedup and diversity score                        |

Formula:

`score = 0.30*aliasMatch + 0.30*entityOverlap + 0.20*freshness + 0.10*sourceQuality + 0.10*novelty`

## I/O contract

- **Input:** `{ tickerId: string }`
- **Reads:** `GET /api/analysis?tickerId=...&unanalyzed=true`
- **Writes:** `POST /api/analysis` (bulk KG + relevance updates)

| `AGENT_DATA_API_URL`         | Yes      | Base URL for data API calls                                |
| `OPENAI_API_KEY`             | Yes      | LLM provider key                                           |
| `OPENAI_MODEL`               | Yes      | Model id for extraction/scoring prompts                    |
| `AGENT_REGISTRY_URL`         | No       | Needed for auto-register                                   |

| `AGENT_PUBLIC_URL`           | No       | Needed for auto-register                                   |
