## What is this monorepo?

**MediaPulse** is the product: an AI-assisted newsletter and pipeline platform.

The codebase is organized into two **domains**:

- **Hermes** — Orchestration: dashboard, worker/scheduler, auth API, registry API, and the **orchestration** database (pipelines, schedules, API keys, **admin** users).
- **Mediapulse** — Product data and runtime: **agent-data-api**, **domain API** (Mediapulse DB + Hermes integration), user registration, and HTTP **agents** under `apps/mediapulse/agents/*`, backed by the **Mediapulse** database (tickers, newsletters, knowledge graph, and related tables).

## How the domains connect

Hermes **orchestrates** work (pipelines, schedules, invoking agents). It does **not** own newsletter, ticker, or knowledge-graph tables. When Hermes needs that kind of data—**data-source expansion**, CRUD for Mediapulse entities in the dashboard, and similar—it calls the **Mediapulse domain API** over HTTP. The Hermes app does not connect to the Mediapulse database for those features.

Tables, identities, and detailed runtime flows are described in **[Hermes and Mediapulse domains](/architecture/domains)**.

## Stack

- **Monorepo:** pnpm workspaces, Turborepo
- **Hermes apps:** Next.js dashboard, Bun worker; Bun + Hono for agent-auth-api and agent-registry-api
- **Mediapulse apps:** Bun + Hono for agent-data-api and domain-api; Next.js for user-registration; agents as small HTTP services with `@workspace/agent-runtime`
- **Database:** PostgreSQL with Prisma (`@hermes/orchestration-database` and `@mediapulse/database`)
- **Env:** `@hermes/env` and `@mediapulse/env` (T3 Env / env-to-t3), not raw `process.env`

## Running the project

For installation, environment setup, database migrations, and how to run each app, see [Getting Started](/getting-started).

Quick reference:

- **Database:** `docker-compose up` then run Prisma migrate/generate for `packages/hermes/orchestration-database` and `packages/mediapulse/database` (see Getting Started).
- **Hermes dashboard:** `pnpm dev --filter=@hermes/dashboard` (port **3001**)
- **APIs:** `pnpm dev --filter=@hermes/agent-auth-api`, `pnpm dev --filter=@mediapulse/agent-data-api`, `pnpm dev --filter=@hermes/agent-registry-api`
- **Agents:** `apps/mediapulse/agents/<name>` — each has its own `.env.local` when needed
